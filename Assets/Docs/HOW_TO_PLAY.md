# Un Día Con Emociones — TLP (MVP)

## Estructura de Assets
- `Scripts/` — código del juego (Core, Affect, Narrative, Skills, Safety, Presentation, Data)
- `Scenes/` — Boot, Day, Debrief (+ SampleScene de plantilla)
- `Resources/Content/` — ScriptableObjects generados
- `Editor/` — menús de setup y build
- `Art/` — placeholders de arte
- `Docs/` — notas del proyecto
- `Settings/` — URP / plantilla Unity

## Jugar en el Editor
1. Abrí `Assets/Scenes/Boot.unity`
2. Press Play

## Build Windows
- Menú: `SeriousGame BPD / Build Standalone Windows 64`
- Ejecutable: `Builds/Windows/UnDiaConEmocionesTLP.exe`
